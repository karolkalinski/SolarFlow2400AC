## Connecting to ZenHA Mqtt with MQTTExplorer

1. Fetch auth cloud key from you Zendure app
2. Use obtainZednureMqttDetails.py to get MQTT connection details
3. Configure MQTTExplorer with obtained data
4. In advanced configuration add subscription
